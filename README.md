# Редакционная аналитика DEMO

Внутренний дашборд для рассылок ГФ и ГЗ. Он читает данные непосредственно из Google-таблицы «DEMO-рассылки ГФ и ГЗ — редакционная аналитика» и показывает их команде как обычный сайт.

## Что уже работает

- общий план-факт и процент выполнения;
- R / Y / G по шести продуктам;
- динамика по неделям;
- реестр отправленных писем с поиском и фильтрами;
- карточка письма: тема, сегмент, доставлено, OR, CTOR, R / Y / G, комментарии и ссылки;
- тексты редакционного плана, active-demo и live-досылов;
- лучшие темы, инфоповоды и правила методики;
- единые данные для всей команды;
- обновление данных одним ответственным;
- загрузка нескольких `.mhtml`-отчётов Sendsay прямо на сайте;
- автоматический импорт новых отчётов из подключённой папки Drive;
- защита от повторной загрузки и отдельный статус для писем, которые ещё не сопоставлены с DEMO.

## Однократная публикация в Google Workspace

1. Откройте исходную Google-таблицу.
2. Выберите **Расширения → Apps Script**.
3. Замените содержимое `Code.gs` файлом `Code.gs` из этого репозитория.
4. Создайте HTML-файл с именем `index` и вставьте в него содержимое `index.html`.
5. В настройках проекта включите показ файла манифеста и замените `appsscript.json` версией из репозитория.
6. Выберите функцию `setup` и нажмите **Выполнить**. Подтвердите доступ к таблице и папке с отчётами Sendsay.
7. Нажмите **Развернуть → Новое развертывание → Веб-приложение**:
   - выполнять от имени: **я**;
   - доступ: **все пользователи вашего домена**.
8. Откройте сайт, вставьте ссылку на папку с отчётами Sendsay и нажмите **Подключить папку**. Ссылка сохранится внутри Apps Script и больше не понадобится.
9. Отправьте полученную ссылку команде.

После этого участникам команды ничего настраивать не нужно. На сайте кнопку «Обновить» видит только ответственный: она забирает новые `.mhtml` из папки Drive, сохраняет разобранные показатели в скрытый технический лист и обновляет реестр. Там же можно выбрать несколько отчётов с компьютера — сайт положит их в ту же папку и сразу обработает.

При первом запуске папки обработка идёт небольшими партиями, чтобы крупные MHTML-файлы не упирались в лимит времени Apps Script. Интерфейс автоматически повторяет загрузку и показывает остаток. Повторно уже обработанные файлы не читаются, пока они не изменились.

## Файлы

- `Code.gs` — чтение и нормализация данных Google Sheets;
- `index.html` — интерфейс сайта;
- `appsscript.json` — разрешения и режим веб-приложения.

GitHub Pages показывает демонстрационный режим интерфейса. Рабочая доменная версия запускается как Google Apps Script Web App.
